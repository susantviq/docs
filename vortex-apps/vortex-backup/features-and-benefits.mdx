Below is the full Vortex Backup feature list with the business outcome each capability is designed to deliver.

## Features

### Comprehensive data protection (19 entity types)

Backs up and restores 19 different Shopify data types covering your entire store: Products, Collections, Customers, Orders, Discount Codes, Discount Automatic, Blogs, Pages, Files, Themes, Gift Cards, Navigation Menus, URL Redirects, Markets, Delivery Profiles, Locations, Price Lists, Catalogs, Metafield Definitions, Metaobject Definitions, Metaobjects.

### Real-time backup

The Vortex Backup app actively listens to Shopify store webhooks and tracks changes in real time for: Products, Collections, Customers, Orders.

### Manual backup

Applicable for data entities which do not have webhooks. Take full backups by clicking the Backup button. Manual backup is done for: Discount Codes, Discount Automatic, Blogs, Pages, Files, Themes, Gift Cards, Navigation Menus, URL Redirects, Markets, Delivery Profiles, Locations, Price Lists, Catalogs, Metafield Definitions, Metaobject Definitions, Metaobjects.

### Theme backup and restore

Full theme backup including all theme files, stored as a ZIP archive in Azure Blob Storage. Restore creates a new theme from the backed-up ZIP, preserving all templates, sections, snippets, layouts, CSS / JS assets, and settings.

### File and media backup

Media files (images, videos, documents, 3D models) are backed up to Azure Blob Storage. Restore uses secure, time-limited SAS URLs to transfer files back to Shopify. Supports all Shopify file types: images, videos, external videos, documents, and 3D models.

### Version tracking

Tracks changes to your store, providing a complete history of updates and backups. Allows you to restore to any previous version safely.

### Side-by-side version comparison

Compare any two versions of a data entity side by side in Summary or Source Code (JSON) view. See the exact differences between versions before deciding to restore.

### Quick data recovery

Restores from the last good backup with minimal downtime on Shopify. Minimises disruption to business operations and ensures a seamless customer experience.

### Smart collection handling

Smart collections with rules are restored with their automation rules intact. Product associations are automatically populated by Shopify based on the restored rules. Manual collections have their product associations explicitly restored.

### Inventory restore by location

Product inventory quantities are restored per location, matched by location name. Ensures correct stock levels across all fulfilment locations.

### Sales channel publishing

Product sales channel (publication) assignments are compared and synchronised during rollback. Products are published to or unpublished from channels to match the backed-up state.

### Metafield and metaobject support

Full backup and restore of custom metafield definitions, metaobject schemas, and individual metaobject records. Entity-level metafields (on products, customers, collections, pages, blogs) are included in their parent entity's backup and restore.

### Ease of use

A simple web interface for managing backup and restore tasks on the Shopify platform. Requires no technical expertise, making it accessible for all users.

## How this compares to Shopify-native tooling

Shopify ships activity logs but no rollback. The platform's theme version history covers themes only, leaves the other 18 entity types unprotected, and offers no per-record undo. Vortex Backup adds real-time backup for the four webhook-supported entities, manual full backup for everything else, and per-record restore across all 19. Built around the per-entity Shopify ID, so a rollback hits the exact record you select and nothing else.

## FAQ

### Does Vortex Backup cover Shopify Plus features?

Yes. Markets, B2B Catalogs and Price Lists, and Metaobjects (which are typically Shopify Plus territory) are all covered.

### Are orders restorable?

Orders are backed up but not restorable. Order data is protected to preserve financial and legal records. The historical versions are visible in the Restore Centre for compare and audit, but restore is disabled on Orders.

### Will real-time backup miss changes if the app is offline?

Shopify retries failed webhook deliveries for 48 hours. If Vortex Backup is briefly offline, queued webhook events are processed when service resumes. For the rare extended outage, Shopify's webhook retry window covers most real-world scenarios; for a belt-and-braces approach, run a manual backup of the four real-time entities after a known outage.
