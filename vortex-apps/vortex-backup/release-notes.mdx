The following are the product fixes and releases implemented since Vortex Backup (Shopify) went live. For the in-app audit trail feature, see [Change Logs and Restore Centre](/vortex-apps/vortex-backup/change-logs-and-restore). For BigCommerce, see [RollbackPro Release Notes](/vortex-apps/rollback-pro/release-notes).

**Release Notes May 2026**

- Installing Vortex Backup now follows the same setup flow as StagingPro, Vortex Staging and RollbackPro.

**Release Notes April 2026**

Vortex Backup relaunches inside the unified Vortex Apps toolkit

- Vortex Backup shipped alongside RollbackPro with the same modern dashboard and side-by-side version comparison, built for Shopify stores.

**Release Notes January 2026**

- The first version of VIQ Backup (Shopify) shipped, giving Shopify merchants automated backup coverage. This has since grown into Vortex Backup.
