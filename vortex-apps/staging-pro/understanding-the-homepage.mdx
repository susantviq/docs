The StagingPro home tab is the operational control surface for your linked BigCommerce environments. Every Staging, UAT and Integration environment you have connected to Production appears as a row, with the latest data migration status, theme version, and quick links into the storefront and control panel.

## The Home tab grid

Each row on the grid represents one linked environment. The columns:

<Frame>
  ![Dashboard 1](/images/Dashboard-1.png)
</Frame>

| Column | What it shows |
| --- | --- |
| **Name** | The environment type (Production, Staging, UAT, etc.), with the store hash underneath — click the hash for store info. |
| **View Store** | Opens the frontend storefront URL for that environment in a new tab. Use it to spot-check what the customer would see. |
| **Control Panel** | Opens the BigCommerce admin Control Panel for that environment. Useful when you need to verify a setting after a migration. |
| **Branch** (GitHub only) | A View link to the environment's Git channel branch; shows a Deploying / Reverting badge while a code deployment is in flight. |
| **Date Created** | Date and time of the most recent migration task affecting this environment, not the date the environment itself was created. |
| **Migration Status** | A live progress bar with percent and the start time; once complete, an end message such as "Bulk migration completed", plus a Failed / In Progress badge when applicable. |
| **Theme** | The code release version from Git theme deployments (bumped 0.1 per deploy); "—" if the environment has never had a code deployment. It does not reflect themes copied by a data migration. |

## Drilling into migration detail

Environment rows show a live progress bar for any in-flight migration. For the full run detail, switch to the **Migration History** tab and click **Open →** on the run's row:

<Frame>
  ![M Igration Details](/images/MIgration-Details.png)
</Frame>

The run detail shows:

- Live progress: current phase, items done, rate, and a running time estimate.
- **Breakdown by Phase**: per-entity **Total / Created / Updated / Matched / Failed / Skipped** counts (plus **Deleted** on Make Exact Copy runs), with section and sub-component rows inline.
- The itemised **issue log**: Failed, Skipped, Warnings, and Fixed automatically, each with a plain-English reason.
- **Pause / Resume / Cancel** controls for in-flight runs.

See [Migration History and Code Deployments](/vortex-apps/staging-pro/history-and-rollback) for the full reference.

## Home tab summary

Three operational uses:

1. **At-a-glance health check**, are all environments listed correctly? If a row has stale dates or a half-finished progress bar, it may need attention.
2. **Fast environment access**, View Store and Control Panel save the keystrokes of finding the right BigCommerce URL when you flip between Production and the sandboxes.
3. **Deploy version check**, the Theme column shows the latest code release version deployed via Git to each environment. If your developers have just shipped a theme through Code Deployments, this is where you verify it landed.
