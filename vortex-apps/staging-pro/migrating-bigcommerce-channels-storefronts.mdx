## Marketplace Channels

-

If the source store has no Marketplace channel, there is no mapping and no channel migration

-

If the source store has Marketplace channel(s):

  -

If the source store and destination store has 1 channel each, then the channels are auto mapped - and will migrate from source to destination

  -

If the destination store has no channel , the user can map to the relevant (new) channel in the destination

## Multi Storefront (MSF) Channels

MSF_enabled refers to a store with more than 1 storefront/channel. Hence the following conditions below are applicable to MSF migration scenarios

| **IF Condition** | **AND Condition** | **THEN Action** | **Popup message** |
| --- | --- | --- | --- |
| Source store is NOT MSF_enabled **×** | Destination store is NOT MSF_enabled **×** | BigCommerce Storefront will automatically map to the destination BigCommerce Storefront as both have a single channel id value of 1. | _“Your Primary Storefront can be migrated from Source to the Destination”_ |
| Source store is NOT MSF_enabled **×** | Destination store IS MSF_enabled ✔ | Similar to the above, the BigCommerce primary storefront will automatically map to the destination BigCommerce primary storefront. In summary the two primary stores with channel id value of 1 will map automatically. | _“Your Primary Storefront can be migrated from Source to the Destination”_ |
| Source store IS MSF_enabled ✔ | Destination store is NOT MSF_enabled **×** | Relevant popup/Notification will show below | _Your Primary Storefront (Channel ID 1) can be migrated from Source to the Destination (Channel ID 1)._   _“Other selected channels cannot be moved because the destination store is NOT multi-storefront enabled.”_ |
| Source store IS MSF_enabled ✔ | Destination store IS MSF_enabled ✔ | **Channel mapper** will display the available channels from source and available channels from destination.  -   It does so by getting the mapping info from StagingPro channels mapping   -   All the Channels not yet mapped can be mapped by the user.  -   The migration then takes place between the mapped channels from the source to the destination store. |  |

## Channel Mapper

When the Source store and Destination store are both MSF_enabled ✔, the following channel mapping will display on the ‘Bulk Content Migration’ tab where you can select the destination channel (or create new channel) and click ‘Apply’ to save the mapping changes.
