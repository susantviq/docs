The CloudHub Account section is everything tied to the user record itself: profile details, password, the active trading entity (VendorDB), and the sign-out action. It is reached from the **247 avatar** in the top-right of every CloudHub page.

This page is the section landing. Each subpage covers one task in depth.

## How to open the account menu

1. Click the orange-and-red **247** badge in the top-right of the CloudHub navigation bar. The badge sits between the navigation links and the padlock / expand / notebook icons.
2. A dropdown menu appears below the avatar with four entries:

| Entry | What it does |
| --- | --- |
| **Switch VendorDB** | Opens the Switch VendorDB Details modal so you can change the active trading entity. See [Switch VendorDB](/vortex-apps/cloudhub/account/switch-vendordb). |
| **Edit Account Profile** | Opens the Edit User screen at `Configure > User Settings > Edit User`. See [Edit user and password](/vortex-apps/cloudhub/account/edit-user-and-password). |
| **Change Password** | Opens the Change Password screen at `Configuration > User Settings > Change Password`. See [Edit user and password](/vortex-apps/cloudhub/account/edit-user-and-password). |
| **Sign Out** | Ends your session and returns you to the [CloudHub login page](/vortex-apps/cloudhub/login). |

## What lives in this section

| Page | What it covers |

## Why account settings matter operationally

The user profile drives **Login Countries**, an IP-restriction control that locks your account to specified geographies. If your team only operates from the UK and France, set Login Countries to those two and CloudHub refuses sessions originating from any other IP-geolocated country. This is a meaningful security posture for marketplace accounts that hold customer PII and payout data.

The VendorDB switcher determines which **trading entity's data** every other page in CloudHub is showing. If you manage multiple brands or entities, every dashboard view, every order queue, every repricing rule is scoped to the active VendorDB. Knowing which one is loaded prevents the classic mistake of repricing the wrong entity's catalogue.

## Common questions

**I do not see the avatar menu.**
The avatar is the orange-and-red **247** badge in the top-right. On narrow viewports it can sit close to the right edge of the screen. Maximise the browser window or scroll the navigation horizontally if needed.

**Can I add a second user to my CloudHub account?**
User invites are managed from the [Configure] section under User Permissions and Settings. That page is documented in a later batch. In short: a super-admin user invites the new user by email, assigns a role, and CloudHub sends an invite email with a setup link.

**What happens when I click Sign Out?**
Your session token is invalidated server-side and you are returned to the [CloudHub login page](/vortex-apps/cloudhub/login). Any unsaved work in open forms is lost, so save before you sign out.
