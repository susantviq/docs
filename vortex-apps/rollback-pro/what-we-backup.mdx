RollbackPro captures fourteen BigCommerce entity types with their full field set. This page is the field-by-field reference. Use it to confirm before relying on RollbackPro for a specific recovery scenario that the field you care about is in the backup.

## 1. Products

### Core fields

- Name, SKU, Type (physical, digital, etc.), Description.
- Price, Cost Price, Retail Price, Sale Price, MAP Price.
- Weight, Width, Depth, Height.
- Tax Class ID, Product Tax Code.
- Inventory Level, Inventory Warning Level, Inventory Tracking.
- Availability, Availability Description.
- Condition, Is Condition Shown.
- Sort Order.
- Is Visible, Is Featured, Is Active.
- Is Free Shipping, Fixed Cost Shipping Price.
- UPC, GTIN, MPN.
- Bin Picking Number.
- Warranty.
- Layout File.
- Search Keywords.
- View Count.
- Related Products.
- Brand ID.
- Categories (list of category IDs).

### Ordering and pre-order

- Order Quantity Minimum / Maximum.
- Is Preorder Only, Preorder Message, Preorder Release Date.
- Is Price Hidden, Price Hidden Label.

### SEO and Open Graph

- Page Title.
- Meta Keywords, Meta Description.
- Custom URL (path, is\_customized).
- Open Graph Type, Title, Description.
- Open Graph Use Meta Description, Use Product Name, Use Image.

### Gift wrapping

- Gift Wrapping Options Type.
- Gift Wrapping Options List.

### Sub-entities

| Sub-entity | Fields captured |
| --- | --- |
| Custom Fields | Name, Value |
| Bulk Pricing Rules | Quantity Min, Quantity Max, Type, Amount |
| Videos | Title, Description, Sort Order, Type, Video ID |
| Images | Image File / URL, Is Thumbnail, Sort Order, Description |
| Options | Display Name, Type, Sort Order, Config, Option Values (label, sort order, value data) |
| Modifiers | Display Name, Type, Required, Sort Order, Config, Option Values (with price / weight adjusters) |
| Variants | See section 2 |
| Reviews | Title, Text, Status, Rating, Email, Name, Date Reviewed |
| Channel Assignments | Product ID, Channel ID |

## 6. Orders

Orders are backed up for **version tracking and comparison purposes** only. Historical versions appear in the Restore Center and can be viewed and compared, but not restored.

> Orders cannot be restored. BigCommerce orders cannot be deleted, and restoring would trigger actions like customer notification emails. Order data is backed up for reference.

## What is not backed up

A handful of BigCommerce data classes are out of scope due to platform constraints:

- **Banner and homepage carousel images**, BigCommerce does not expose APIs.
- **WebDAV and Image Manager images**, no API for transfer.
- **B2B Edition entities** (companies, addresses, users, quotes, invoices, super admins), planned for a future release.
- **Price Lists**, planned for a future release.
- **Archived orders**, currently excluded.
- **Multi-location inventory beyond the default location**, planned for a future release.

## FAQs

**Q. Are product images backed up?** The image metadata (URL, alt text, sort order, is\_thumbnail) is backed up. The image files themselves are loaded from BigCommerce CDN at restore time. If the source CDN URL is broken or the image was deleted from WebDAV, the image will not appear on the restored product, but the rest of the product data restores correctly.

**Q. Are reviews backed up?** Yes, as a sub-entity of Products: title, text, status, rating, email, name, and date reviewed are captured.

**Q. Are customer addresses captured?** Yes, as part of the Customer record alongside form fields, store credit, and channel associations.

**Q. Are abandoned cart records backed up?** The abandoned-cart email template is backed up. Individual abandoned cart events are not.

**Q. Why is the backup count for Pages higher than my BigCommerce control panel shows?** Because BigCommerce does not provide a webhook for deleted pages. RollbackPro retains the historic page record (so you can restore it) even after deletion. The dashboard count therefore counts more pages than your control panel currently shows.
