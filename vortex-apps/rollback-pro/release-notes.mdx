The following are the product fixes and releases implemented since RollbackPro (BigCommerce) went live. For the in-app audit trail feature, see [Change Logs and Webhook Logs](/vortex-apps/rollback-pro/change-logs). For Shopify, see [Vortex Backup Release Notes](/vortex-apps/vortex-backup/release-notes).

**Release Notes June 2026**

- BigCommerce Backup installs now include full Insights access as part of setup, rather than limited access.

**Release Notes May 2026**

- RollbackPro adds point-in-time restore and selective bulk restore, so you can restore your store to a specific moment or choose exactly which records to bring back, instead of an all-or-nothing rollback.
- Installing RollbackPro now follows the same setup flow as StagingPro and Vortex Staging.

**Release Notes April 2026**

RollbackPro relaunches inside the unified Vortex Apps toolkit

- A new native dashboard shipped with four tabs, hero stats, and a first-run onboarding banner.
- Added side-by-side version comparison, showing exactly what changed between the current and a prior version before you restore.

**Release Notes January 2026**

- The first version of VIQ Backup (BigCommerce) shipped, giving merchants automated backup coverage directly from the Connections page. This has since grown into RollbackPro.
