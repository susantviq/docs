Written articles wait in **Needs approval** until you are happy with them.

## Review an article

Open an article to read it. Use the views above it:

- **Read:** see it as it will look. Switch between **Desktop** and **Phone**.
- **Write:** edit it directly.
- **HTML:** edit the source.

Press **Save** to keep your changes. **Save** also stores a changed banner image.

## The side panel

| Tab | What it shows |
| --- | --- |
| **Claims** | Statements not backed by anything you gave the app |
| **Checks** | Links, tables, anchors and other issues |
| **Links** | The article's links |
| **Keywords** | The keywords it targets |
| **Image** | The hero image, and your image library |
| **Versions** | Every saved version of the article |

For a claim, you can remove the sentence, add a source, or ignore it.

## Send it back for a rewrite

Press **Send back to rewrite** and say what should change, such as "make the intro warmer". Come back in 2 to 3 minutes. The new version appears on the page and in **Versions**. Save your own edits first, because a rewrite replaces the draft.

If a rewrite hasn't come back after 15 minutes, the page lets you send the same request again.

## Versions

Click a version to see it. **Back to current** returns you to the draft, and **Restore** makes that version current. Restoring is saved as a new version, so nothing is lost.

## Approve

Press **Approve**. If issues are still open, the button says **Approve anyway** with the number of issues. Once approved, the button changes to **Publish**.
