Billing goes through Shopify, and you can change plan at any time without contacting us.

## Compare plans

| | Free | Growth | Pro |
| --- | --- | --- | --- |
| **Price** | Free | $39 a month | $99 a month |
| **AI visibility questions a month** | 50 | 300 | 1,000 |
| **Content plans a month** | None | 1 | 3 |
| **Article ideas from AI tests** | No | Yes | Yes |
| **Image compression** | No | Yes | Yes |
| **Fix all** | No | No | Yes |

Shopify's plan page shows the current prices, yearly billing and any free trial.

## How usage is counted

- **Questions:** one question counts once in a run, however many assistants answer it. Asking it again in a later run counts again. Only answered questions count.
- **Content plans:** each plan you create counts in the month you create it.
- **Reset:** allowances start again on the first day of each calendar month.

If a run has more questions than you have left, it won't start, and the app says how many remain.

## Change your plan

<Steps>
  <Step title="Open Settings">
    Your plan and this month's usage are at the top of **Settings**.
  </Step>
  <Step title="Press Upgrade or Change plan">
    Shopify's plan page opens. Choose a plan and approve it.
  </Step>
</Steps>

The change counts straight away.
