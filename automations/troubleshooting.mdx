## Building an automation

<AccordionGroup>
  <Accordion title="The page says I have no builds left today">
    Each new automation you start counts as one build, and your workspace has a daily limit. The line under the page title says when the next build is available. Changing an automation you already started does not use a build, so open your draft and carry on there.
  </Accordion>
  <Accordion title="Ask Viq says it could not turn my request into steps">
    Say it another way. Include what should happen, when it should happen and which app the result goes to. For example: "Every morning at 8, email me the orders that are still waiting to be shipped."
  </Accordion>
  <Accordion title="Ask Viq says I asked for this before">
    You asked for the same thing earlier and did not save it. Select **Open that build** to carry on from there, or **Build it again** to start fresh. Opening the earlier build does not use a build for the day.
  </Accordion>
  <Accordion title="A step says Needs an app">
    An app the step uses is not connected on this store profile. Select the button under that step in the chat to connect the app or add it to the profile. Only a workspace admin can do this. If you are not an admin, select **Ask an admin**.
  </Accordion>
  <Accordion title="A step says Not supported yet">
    Vortex IQ cannot use that app in automations yet. Ask for it with the button under the step, or tell Ask Viq to leave that step out.
  </Accordion>
  <Accordion title="A step says Needs help">
    Ask Viq tried three times and could not get the step to work. The step says why. If a detail is missing, such as a page address or who an email goes to, give it in the chat. Otherwise open the step, select the **Logic** tab, and choose **Ask Viq to change it** or **Carry on without it**.
  </Accordion>
  <Accordion title="The Save button cannot be selected">
    You can save when every step shows **Ready** and nothing is still building. Look for a step that needs an app or needs help. If the Save window lists a check that did not pass, tell Ask Viq what to change. To keep unfinished work, select **Save as draft**.
  </Accordion>
  <Accordion title="Ask Viq refused my message because of a key">
    Never type passwords, API keys or tokens in the chat. Connect the app in its own form instead, from the button in the chat or in **Settings**, under **Connected Sources**.
  </Accordion>
  <Accordion title="My file or picture was refused">
    A file must be a workflow exported from n8n, Shopify Flow or Vortex IQ, and smaller than 4 MB. A picture must be PNG, JPEG or WebP, and smaller than 3 MB. A Vortex IQ export can only be attached to a new, empty chat. If Ask Viq has asked you a question, answer it first, then attach the file.
  </Accordion>
  <Accordion title="The page says Vortex IQ could not read this yet">
    The page could not reach the automation service just now. Wait a moment and reload. Nothing you saved is lost. If it keeps happening, contact support.
  </Accordion>
</AccordionGroup>

## Running an automation

<AccordionGroup>
  <Accordion title="My automation is saved but shows Not running">
    It cannot start by itself yet. Open it and save it again. The chat then says what is missing, in a line that starts with "It does not run on its own yet". Common reasons are a schedule without a time, or a store event Vortex IQ cannot listen to yet.
  </Accordion>
  <Accordion title="My automation was paused and I did not pause it">
    Vortex IQ pauses an automation when one of its steps stops working and needs repairing, or when the automation is started too many times in a minute. It sends an email about the pause to the person who last saved the automation. Look on the **Waiting for you** tab for a fix to approve, or select **Resume** on the list to switch it on again.
  </Accordion>
  <Accordion title="A run failed">
    Open the run on the **Runs** tab. It shows the step that failed, why, and what to do. Then select **Run again**. See [When a run fails](/automations/runs-and-results#when-a-run-fails).
  </Accordion>
  <Accordion title="Run again was refused">
    The message says why. The usual reasons: the event that started the run is no longer kept (a failed run's event is kept for a week), the run was already run again, the automation now starts another way, or it is switched off.
  </Accordion>
  <Accordion title="There is no Run now button">
    **Run now** is there for a saved automation with no unsaved changes. If the header shows a **Save version** button, save first.
  </Accordion>
  <Accordion title="It ran at a different time than I expected">
    A schedule runs in its own time zone. Open the Save window or **Change when this runs** and check **Time zone**. The list and the calendar show times in your own time zone, which may differ.
  </Accordion>
  <Accordion title="The run does not show the value I asked for">
    A run shows counts and one short result per step. It never shows text that could contain people's details, such as customer or order data. Ask Ask Viq to send the result by email or to a chat channel instead.
  </Accordion>
  <Accordion title="A change I made in the chat is not live">
    A change is live only after you save it as a new version. Until then the automation keeps running as the last saved version.
  </Accordion>
</AccordionGroup>

## Approvals and apps

<AccordionGroup>
  <Accordion title="A card on Waiting for you says Expired">
    A single change waits for 15 minutes. After that nothing is sent. If you still want the change, ask for it again.
  </Accordion>
  <Accordion title="Do I have to approve every run?">
    No. When you save an automation you approve what that version can read and change, for every run. You approve again only when you save a new version, or when Vortex IQ has repaired a step.
  </Accordion>
  <Accordion title="I cannot connect an app">
    Only a workspace admin can connect an app or add one to a store profile. Select **Ask an admin**. The automation carries on once the app is connected.
  </Accordion>
  <Accordion title="The app I need is not in the list">
    Describe the automation anyway and name the app. If Vortex IQ cannot use it yet, you can ask for it from the step, and your request appears under **Connector requests** on the **Connections** tab.
  </Accordion>
  <Accordion title="An app shows Expired · reconnect">
    Its sign-in ran out or was withdrawn. Select **Connect** on the **Connections** tab and sign in again. Then run the failed automation again.
  </Accordion>
</AccordionGroup>

## General questions

<AccordionGroup>
  <Accordion title="Does building an automation change my store?">
    No. While building, Ask Viq only reads your store to test each step. Steps that change something are previewed, not sent. Changes happen only in real runs, after you have saved and approved the automation.
  </Accordion>
  <Accordion title="Can my colleagues see my automations?">
    Yes. Saved automations and their runs are listed for everyone in your workspace. A draft is visible only to the person who started it, on the store profile they built it on.
  </Accordion>
  <Accordion title="Can I move an automation to another store?">
    Export it, switch to the other store profile, and attach the file to a new chat in the builder. The file holds no keys and no connections, so the other store uses its own apps. Ask Viq builds and tests it again there. This works best when both stores are on the same platform, because the steps name the apps they use.
  </Accordion>
  <Accordion title="How do I get help with a run?">
    Open the failed run on the **Runs** tab and copy the code after **Reference for support**. Send it to [Vortex IQ support](https://www.vortexiq.ai/contact-us).
  </Accordion>
</AccordionGroup>
