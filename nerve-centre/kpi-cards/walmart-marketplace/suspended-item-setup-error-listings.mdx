## At a glance

{/* HUMAN_AUTHORED:tldr */}
> Suspended / Item Setup Error Listings counts the items that Walmart has pulled from sale or refused to publish because of a setup problem. These are listings earning zero, often over a fixable data issue such as a missing required attribute or a rejected image. Because any non-zero count means lost sellable inventory, this card is treated as a hero signal.

| | |
| --- | --- |
| **What it counts** | The number of Walmart Marketplace listings in a suspended or item setup error state. |
| **Sample type** | Backend API data from Walmart Marketplace, refreshed on the standard data refresh. |
| **Why it matters** | Suspended and setup-error items cannot sell, so every one is lost revenue and a sign that catalogue data needs fixing before the item can go live. |
| **Reading the value** | Lower is better; the target is zero, and any positive number needs attention. |
| **Currency** | count |
| **Time window** | `RT` |
| **Alert trigger** | `>0` |
| **Sentiment key** | `wal_suspended_listings` |
| **Roles** | owner, operations |
{/* /HUMAN_AUTHORED:tldr */}

## Calculation

The value is derived by counting Walmart Marketplace listings that the platform reports as suspended or in an item setup error state at the time of the refresh. It is a real-time snapshot, so it reflects the current health of the catalogue rather than an average over a window. See the At a glance summary for the unit, and the worked example below for how the count reads in practice.

## Known limitations / merchant FAQs

{/* HUMAN_AUTHORED:faqs */}
**Q: How often does Suspended / Item Setup Error Listings update?**
The card refreshes on the standard data refresh (typically every 30-60 minutes for live integrations). For real-time signals, force a manual refresh from the dashboard.

**Q: Why does my Walmart Seller Center show a different number?**
Seller Center may group several status types differently from how Vortex IQ rolls suspended and setup-error items into one count. Checking the item-level status filter usually reconciles the two views.

**Q: How quickly do fixed items leave this count?**
Once a corrected item is resubmitted and Walmart republishes it, it drops out of the count at the next refresh. If it lingers, the resubmission may still be in Walmart's review queue.

**Q: Can I customise the alert threshold?**
Yes, alert thresholds are configurable per profile in the Alert Rules tab. Adjust to match your business baseline rather than relying on the generic default.
