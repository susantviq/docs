## At a glance

| | |
| --- | --- |
| **What it measures** | Request-volume change vs the prior 30d; a silent stall means the integration or key broke. |
| **Source** | OpenAI Admin API (derived) |
| **Time window** | `30D vsP` |
| **Alert trigger** | `drop >50% vsP` |
| **Sensitivity band** | `ai_usage_trend`: good 0, bad -50 (trend based (usage drop = bad)) |
| **Roles** | owner, engineering |
| **Chart** | kpi |

> Requires an organisation Admin API key; with a plain key this card shows no data.

## Calculation

```
Request-volume change vs the prior 30d; a silent stall means the integration or key broke.
```

Computed by the OpenAI engine from daily Admin-report buckets over a 60-day window (current 30 days plus the previous 30 for trend comparisons), refreshed on the standard sync. The engine degrades to no data rather than estimating.

### Tracked live in Vortex IQ Nerve Centre

Connect OpenAI in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
