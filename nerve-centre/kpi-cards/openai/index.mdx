[KPI Cards](/nerve-centre/kpi-cards) / **OpenAI** · [Sentiment](/nerve-centre/kpi-cards/openai/sentiment)

Vortex IQ tracks the AI spend and usage of the connected OpenAI organisation: spend level and trend, token and request volume, model mix and prompt-cache effectiveness. Cards derive from /v1/models plus the organisation Admin cost and usage reports. Spend and usage cards require an organisation Admin API key; a plain project key renders only the model cards.
