## At a glance

| | |
| --- | --- |
| **What it measures** | getChat.result.title (fallback first_name/id) for the configured chat_id. Same gating as the member count: chat_id_required with no chat_id, bot_not_in_chat on API failure. |
| **Source** | Telegram Bot API (getChat) |
| **Time window** | `RT` |
| **Alert trigger** | `-` |
| **Roles** | owner, operations |
| **Chart** | kpi |

> Requires a chat id for a channel or group the bot administers; without it this card shows no data.

## Calculation

```
getChat.result.title (fallback first_name/id) for the configured chat_id. Same gating as the member count: chat_id_required with no chat_id, bot_not_in_chat on API failure.
```

Computed live by the Telegram engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.

### Tracked live in Vortex IQ Nerve Centre

Connect Telegram in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
