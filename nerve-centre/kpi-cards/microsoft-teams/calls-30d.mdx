## At a glance

| | |
| --- | --- |
| **What it measures** | Sum of Calls from getTeamsUserActivityCounts(D90) over the last 30d. |
| **Source** | Microsoft Graph usage reports (activity_counts) |
| **Time window** | `30D` |
| **Alert trigger** | `-` |
| **Roles** | owner, operations, engineering |
| **Chart** | kpi |

> Requires the Reports.Read.All application permission (admin consent); without it these activity cards show no data.

## Calculation

```
Sum of Calls from getTeamsUserActivityCounts(D90) over the last 30d.
```

Computed live by the Microsoft Teams engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.

### Tracked live in Vortex IQ Nerve Centre

Connect Microsoft Teams in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
