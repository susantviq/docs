Vortex IQ Nerve Centre tracks **18** KPI pulses for Rollbar stores. Each metric has its own page: definition, calculation, why it matters, and what to do when it moves.

{/* HUMAN_AUTHORED:landing_positioning */}
The Rollbar connector brings the Vortex IQ **AI OS** to engineering teams using Rollbar for real-time error tracking, deployment monitoring, and continuous code improvement across modern application stacks. The **Nerve Centre** tracks 18 KPI pulses covering *Error Rate*, *p95 / p99 Latency*, *Apdex Score*, *MTTA / MTTR*, *Incidents Open*, *Services Healthy / Degraded / Down*, *SLA Compliance*, and *Top Error Types*. **Vortex Mind** investigates when deployment-correlated error spikes appear; **Ask Viq™** answers in plain English with citations back to the source error.
