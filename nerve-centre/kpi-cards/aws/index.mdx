[KPI Cards](/nerve-centre/kpi-cards) / **Amazon Web Services** · [Sentiment](/nerve-centre/kpi-cards/aws/sentiment)

Vortex IQ tracks the AWS spend of the connected account: spend level and trend, cost by service, daily spend, month-end forecast and concentration. Cards derive from STS GetCallerIdentity plus Cost Explorer GetCostAndUsage and GetCostForecast (SigV4-signed, daily granularity). Spend cards require Cost Explorer enabled and the ce:GetCostAndUsage permission; note AWS bills each Cost Explorer API call at $0.01.
