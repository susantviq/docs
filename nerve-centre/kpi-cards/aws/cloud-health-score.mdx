## At a glance

| | |
| --- | --- |
| **What it measures** | 0-100 composite from the daily cost matrix: 100 minus 20 when 30d spend is up >10% vsP (40 when >50%), minus 10 when the month-end forecast runs >10% above trailing 30d spend (20 when >50%), minus 10 when GetCostForecast is unreadable, minus 20 when the latest daily cost bucket is older than 3 days. |
| **Source** | AWS Cost Explorer (derived) |
| **Time window** | `30D` |
| **Alert trigger** | `<70` |
| **Sensitivity band** | `cloud_health_score`: good 90, bad 70 (higher is better) |
| **Roles** | owner, engineering |
| **Chart** | gauge |

> Requires Cost Explorer enabled on the account and the ce:GetCostAndUsage IAM permission; without them this card shows no data.

## Calculation

```
0-100 composite from the daily cost matrix: 100 minus 20 when 30d spend is up >10% vsP (40 when >50%), minus 10 when the month-end forecast runs >10% above trailing 30d spend (20 when >50%), minus 10 when GetCostForecast is unreadable, minus 20 when the latest daily cost bucket is older than 3 days.
```

Computed by the Amazon Web Services engine from daily cost buckets over a 60-day window (current 30 days plus the previous 30 for trend comparisons), refreshed on the standard sync. The engine degrades to no data rather than estimating.

### Tracked live in Vortex IQ Nerve Centre

Connect Amazon Web Services in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
