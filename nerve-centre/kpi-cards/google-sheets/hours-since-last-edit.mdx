## At a glance

| | |
| --- | --- |
| **What it measures** | Drive files.get modifiedTime → now. A feed sheet that hasn't moved in a week is almost always a stalled upstream job. |
| **Source** | Google Sheets API v4 (drive_file_metadata) |
| **Time window** | `RT` |
| **Alert trigger** | `>168h` |
| **Sensitivity band** | `sheet_freshness_hours`: good 24, bad 168 (Lower is better) |
| **Roles** | owner, operations |
| **Chart** | kpi |

## Calculation

```
Drive files.get modifiedTime → now. A feed sheet that hasn't moved in a week is almost always a stalled upstream job.
```

Computed live by the Google Sheets engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.

### Tracked live in Vortex IQ Nerve Centre

Connect Google Sheets in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
