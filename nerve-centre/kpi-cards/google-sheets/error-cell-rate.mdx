## At a glance

| | |
| --- | --- |
| **What it measures** | Share of read rows containing #REF!/#N/A/#DIV/0!/#VALUE! when rendered FORMATTED_VALUE. These poison any importer that trusts the cell. |
| **Source** | Google Sheets API v4 (values_get) |
| **Time window** | `RT` |
| **Alert trigger** | `>1%` |
| **Sensitivity band** | `sheet_error_cell_rate`: good 0, bad 1 (Lower is better) |
| **Roles** | owner, operations, engineering |
| **Chart** | gauge |

## Calculation

```
Share of read rows containing #REF!/#N/A/#DIV/0!/#VALUE! when rendered FORMATTED_VALUE. These poison any importer that trusts the cell.
```

Computed live by the Google Sheets engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.

### Tracked live in Vortex IQ Nerve Centre

Connect Google Sheets in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
