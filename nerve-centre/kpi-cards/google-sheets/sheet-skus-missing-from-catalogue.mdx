## At a glance

| | |
| --- | --- |
| **What it measures** | SKUs in the source-of-truth sheet that don't exist in the live catalogue - orphaned overrides, typos, or a feed that ran ahead of the store sync. |
| **Source** | Google Sheets API v4 (derived) |
| **Time window** | `RT/24h` |
| **Alert trigger** | `>0 orphan SKUs` |
| **Roles** | owner, operations |
| **Chart** | alert_list |

> Requires the relevant access (Drive API for freshness, a seeded header baseline for schema drift, or a configured SKU column for cross-channel joins); without it this card shows no data.

## Calculation

```
SKUs in the source-of-truth sheet that don't exist in the live catalogue - orphaned overrides, typos, or a feed that ran ahead of the store sync.
```

Computed live by the Google Sheets engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.

### Tracked live in Vortex IQ Nerve Centre

Connect Google Sheets in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
