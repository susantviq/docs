## At a glance

| | |
| --- | --- |
| **What it measures** | Empty rows inside the populated range - usually deleted-content gaps that break range-based importers. |
| **Source** | Google Sheets API v4 (values_get) |
| **Time window** | `RT` |
| **Alert trigger** | `>10%` |
| **Sensitivity band** | `sheet_blank_row_rate`: good 2, bad 10 (Lower is better) |
| **Roles** | owner, operations |
| **Chart** | gauge |

## Calculation

```
Empty rows inside the populated range - usually deleted-content gaps that break range-based importers.
```

Computed live by the Google Sheets engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.

### Tracked live in Vortex IQ Nerve Centre

Connect Google Sheets in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
