## At a glance

| | |
| --- | --- |
| **What it measures** | The pricing/cost master sheet and the live store disagree for the same SKU - either the store is selling at the wrong price or the sheet is stale. |
| **Source** | Google Sheets API v4 (derived) |
| **Time window** | `RT/24h` |
| **Alert trigger** | `>0 rows diverge by >5%` |
| **Roles** | owner, operations, finance |
| **Chart** | table |

> Requires the relevant access (Drive API for freshness, a seeded header baseline for schema drift, or a configured SKU column for cross-channel joins); without it this card shows no data.

## Calculation

```
The pricing/cost master sheet and the live store disagree for the same SKU - either the store is selling at the wrong price or the sheet is stale.
```

Computed live by the Google Sheets engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.
