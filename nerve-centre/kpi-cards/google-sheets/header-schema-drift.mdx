## At a glance

| | |
| --- | --- |
| **What it measures** | Diff of the header row (row 1 of the range) against the last-known-good header signature. Catches renamed/reordered/deleted columns the importer depends on. Requires historical seed of the baseline header. |
| **Source** | Google Sheets API v4 (values_get) |
| **Time window** | `RT/vsP` |
| **Alert trigger** | `header signature != last-known-good` |
| **Roles** | owner, operations, engineering |
| **Chart** | alert_list |

## Calculation

```
Diff of the header row (row 1 of the range) against the last-known-good header signature. Catches renamed/reordered/deleted columns the importer depends on. Requires historical seed of the baseline header.
```

Computed live by the Google Sheets engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.
