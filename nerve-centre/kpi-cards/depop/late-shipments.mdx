## At a glance

{/* HUMAN_AUTHORED:tldr */}
> **Late Shipments** is the real-time alert listing every Depop order that has passed its expected dispatch deadline and is still unshipped. Each item is a buyer already waiting longer than promised and a rating, possibly a dispute, in the making. Where the on-time shipping rate tells you the trend, this card tells you exactly which parcels to pack first to stop the damage.

| | |
| --- | --- |
| **What it counts** | The number of orders currently past their dispatch deadline without a recorded dispatch, listed individually. |
| **Sample type** | Backend API data from Depop, refreshed on the standard data refresh, evaluated in real time. |
| **Why it matters** | A late dispatch is the single fastest route to a low rating and a refund request on Depop. This is the most urgent fulfilment list in the shop: every entry is actively eroding reputation right now. |
| **Reading the value** | Zero is the target. Any entry is overdue. The list is a priority queue, ordered by how far past deadline each order sits. |
| **Currency** | count (overdue orders) |
| **Time window** | `RT` (real-time) |
| **Alert trigger** | `any order past its ship deadline` |
| **Sentiment key** | `dep_alert_dispatch_sla_miss` |
| **Roles** | owner, operations |
{/* /HUMAN_AUTHORED:tldr */}

## Calculation

The card lists orders whose expected dispatch window has elapsed without a recorded dispatch, evaluated in real time against Depop's deadline model. Vortex IQ reads order timestamps and deadlines from the Depop integration; the deadline model is set by Depop and described here in general terms.

## Reconciling against Depop

{/* HUMAN_AUTHORED:reconcile */}
**Where to look in Depop's own dashboard:**

Overdue orders appear in your Selling view in the Depop app, flagged against their expected dispatch window. The Vortex IQ list should match those flagged orders; gaps are usually refresh timing.

**Why the Vortex IQ value may legitimately differ:**

| Reason | Direction | What to do |
| --- | --- | --- |
| **Refresh timing.** A dispatch you just marked clears on the next refresh. | Marginal | Force a manual refresh after shipping. |
| **Deadline interpretation.** Vortex IQ mirrors Depop's window but evaluates it continuously. | Marginal | Treat both as the same deadline. |
| **Cancelled orders.** A cancelled order should leave the list. | Lower in Vortex IQ | Confirm the order's live status. |

**Cross-connector reconciliation:** read this with the pending-shipment backlog and the sold-elsewhere card to find why orders go late. For divergence investigations, use Vortex Mind.
{/* /HUMAN_AUTHORED:reconcile */}

## Known limitations / merchant FAQs

{/* HUMAN_AUTHORED:faqs */}
**Q: How often does Late Shipments update?**
It evaluates in real time and refreshes on the standard data refresh. An order leaves the list as soon as you mark it dispatched and the refresh registers it.

**Q: An order is here but I already shipped it. Why?**
Either the dispatch has not registered yet, or it was marked dispatched after the deadline. Force a refresh; if it persists, confirm the dispatch was recorded in Depop.

**Q: Should I refund an overdue order or ship late?**
Depends on the cause. If the item exists, ship immediately and message the buyer. If it is unavailable, refund fast to avoid a dispute. The sold-elsewhere card helps you spot the second case early.

**Q: Can I customise this alert?**
The alert fires on any order past Depop's deadline. Related tolerances, such as backlog alerting, are configurable in the Alert Rules tab.
