Vortex IQ Nerve Centre tracks **79** KPI pulses for Website Performance (PageSpeed + CrUX) stores. Each metric has its own page: definition, calculation, why it matters, and what to do when it moves.

{/* HUMAN_AUTHORED:landing_positioning */}
The Website Performance (PageSpeed + CrUX) connector is the deepest web-performance integration in the Vortex IQ **AI OS** catalogue - 79 KPI pulses combining Google's PageSpeed Insights lab data and Chrome User Experience Report (CrUX) field data into one site-wide picture. The **Nerve Centre** tracks *Core Web Vitals* across mobile and desktop, *CWV Pass Rate by Template*, *Field vs Lab* comparisons, *Slowest LCP / Worst CLS / Worst INP URLs*, *Top Opportunities (bytes / ms)*, *Image / CSS / JS optimisation gaps*, *Third-Party Cost*, *Health Score Trend*, *When Did Speed Get Worse?* timelines, and *Urgent Pages* watchlists - so a Google ranking drop has the actual page-level cause sitting next to it. **Vortex Mind** investigates when a deploy regresses a template's score or a third party inflates request count; **Ask Viq™** answers in plain English - "which pages are killing my mobile pass rate?" - with citations back to the URL.
