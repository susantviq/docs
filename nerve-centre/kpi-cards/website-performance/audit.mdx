Will audit Core Web Vitals (LCP, INP, CLS) per page using PageSpeed Insights API and CrUX.

## What this audit checks

### Core Web Vitals
- LCP &lt; 2.5s
- INP &lt; 200ms
- CLS &lt; 0.1

### Lab vs field
- Lab Lighthouse score
- Field CrUX 75th percentile alignment

### Performance issues
- Render-blocking resources
- Unused JavaScript
- Image format opportunities

## Data sources

- `GET https://www.googleapis.com/pagespeedonline/v5/runPagespeed` - Lab metrics + lighthouse audits
- `GET https://chromeuxreport.googleapis.com/v1/records:queryRecord` - CrUX field data
