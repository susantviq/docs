Vortex IQ Nerve Centre tracks **14** KPI pulses for Fastly stores. Each metric has its own page: definition, calculation, why it matters, and what to do when it moves.

{/* HUMAN_AUTHORED:landing_positioning */}
The Fastly connector brings the Vortex IQ **AI OS** to merchants using Fastly's edge-cloud platform for low-latency content delivery - but the Nerve Centre tracks the *outcomes* Fastly delivery affects, not the CDN's own routing internals. The **Nerve Centre** tracks 14 KPI pulses on *Core Web Vitals* (*LCP*, *INP*, *CLS*, *TTFB*), *CWV Pass Rate*, *Lighthouse Performance / SEO / Accessibility / Best Practices*, *Total Page Weight*, *Speed Index*, *Total Blocking Time*, and *Render-Blocking Resources* - so the speed-to-Google-rankings link stays measured. **Vortex Mind** investigates when mobile CWV slips below the pass threshold; **Ask Viq™** answers in plain English with citations back to the page.
