The Vortex IQ **Nerve Centre** tracks thousands of KPI pulses across more than 200 connectors. These concept pages explain the shared model behind every card, how to read them, why they are tiered, and how cross-platform cards fuse data across connectors.

| Concept | What it covers |
| --- | --- |
| [The KPI Model](/nerve-centre/kpi-cards/concepts/kpi-model) | Every KPI is a card with a fixed metadata shape: id, label, category, format, time window, sentiment, alert, tier. |
| [Key Metrics, Cross-Platform & Standard Tiers](/nerve-centre/kpi-cards/concepts/hero-cross-platform-tiers) | Key Metrics cards answer the top-3 daily questions, cross-platform cards are the kill-shots, standard cards fill the long tail. |
| [The Sentiment Model](/nerve-centre/kpi-cards/concepts/sentiment-model) | The green/red/amber colour each card carries, decided per metric by `sentiment_key`, including dual-axis sentiment. |
| [Time Windows](/nerve-centre/kpi-cards/concepts/time-windows) | The window vocabulary every card runs over: T, 24H, 7D, 30D, 90D, RT, vsP, and when each is used. |
| [Data Freshness](/nerve-centre/kpi-cards/concepts/data-freshness) | Where a card's data comes from and how fresh it is: Native, API-derived, Derived, Real-time, Backdated, Hist, Cost. |
| [The Alert System](/nerve-centre/kpi-cards/concepts/alert-system) | How any card fires an alert when its metric crosses a threshold, routing into the Actions Kanban for triage. |
| [Cross-Platform Kill-Shots](/nerve-centre/kpi-cards/concepts/cross-platform-kill-shots) | Cards that join two or more connectors to compute a value neither tool alone can produce. |
| [Multi-Currency](/nerve-centre/kpi-cards/concepts/multi-currency) | Per-currency display, FX translation for cross-currency aggregation, and the avg / total pattern commerce cards use. |
| [Multi-Property & Multi-Account](/nerve-centre/kpi-cards/concepts/multi-property-and-multi-account) | One OAuth token, many properties or campaigns (the `parent_integration_id` pattern), each rendered as separate cards. |
