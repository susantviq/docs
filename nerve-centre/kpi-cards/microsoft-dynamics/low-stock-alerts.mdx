## At a glance

{/* HUMAN_AUTHORED:tldr */}
> Items where on-hand inventory is below the configured Reorder Point (or Safety Stock Quantity). Forward-looking purchasing queue.

| | |
| --- | --- |
| **What it counts** | `Item.Inventory < Item.Reorder Point` (or `Safety Stock Quantity` if Reorder Point not configured). Each row: SKU, on-hand, reorder point, expected stockout date based on velocity. |
| **Currency** | n/a (count + qty metric). |
| **Time window** | `RT` |
| **Alert trigger** | `any below reorder point` |
| **Sentiment key** | `low_stock` |
| **Roles** | owner, operations |
{/* /HUMAN_AUTHORED:tldr */}

## Known limitations / merchant FAQs

{/* HUMAN_AUTHORED:faqs */}
**Items without Reorder Point?**
Excluded by default. Configure to include via Safety Stock if Reorder Point absent.

**Multi-Location: which Location's Reorder Point?**
Card uses Item-level Reorder Point. Stockkeeping Unit (SKU)-level Reorder Points (per-Location) supported via field map.

**Velocity calculation: how is "expected stockout" computed?**
30-day average sales velocity divided into current on-hand. Drop-Ship lines excluded.
{/* /HUMAN_AUTHORED:faqs */}
