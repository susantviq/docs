## Known limitations / merchant FAQs

{/* HUMAN_AUTHORED:faqs */}
**Healthy return rate?**
B2B: 1-3%. DTC apparel: 15-25%. Electronics: 5-10%.

**Returns vs Sales Credit Memos?**
A Return Order generates a Sales Credit Memo at posting. This card counts the Return Order document; [Sales Credit Memo Value](/nerve-centre/kpi-cards/microsoft-dynamics/msd-credit-memos-value) counts dollars.
