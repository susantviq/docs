> Mean Sales Order line total. Mid-market B2B AOVs typically run 8 to 15x DTC.

## At a glance

{/* HUMAN_AUTHORED:tldr */}
> Average value per Sales Order. `SUM(Sales Header.Amount) / COUNT(distinct Sales Header)` for posted orders in window. Mid-market B2B AOVs typically run 8 to 15x DTC.

| | |
| --- | --- |
| **What it counts** | Posted Sales Invoices in window. |
| **Tax treatment** | Net of VAT. |
| **Currency** | Reporting Currency. |
| **Time window** | `30D vsP` |
| **Alert trigger** | `drop >10% vsP` |
| **Sentiment key** | `aov_trend` |
| **Roles** | owner, finance |
{/* /HUMAN_AUTHORED:tldr */}

## Calculation

Calculated automatically from your Microsoft Dynamics 365 data. See the At a glance summary above for what the metric tracks and the worked example below for a typical reading.

## Worked example

{/* HUMAN_AUTHORED:worked_example */}
US distributor on BC, 30D window 14 Mar to 12 Apr 26.

| | This 30D | Prior 30D | vsP |
| --- | --- | --- | --- |
| Posted Invoices count | 482 | 462 | +4% |
| Total Posted Value | $7.42M | $7.18M | +3% |
| **Avg SO Value** | **$15,395** | **$15,541** | **-1%** |

Order count growth + flat AOV = healthy expansion. Drop in AOV with stable count = rising small-order mix or pricing pressure.
{/* /HUMAN_AUTHORED:worked_example */}

## Known limitations / merchant FAQs

{/* HUMAN_AUTHORED:faqs */}
**B2B vs DTC AOV?**
B2B Net-30: $8K to $80K. DTC: $50 to $500. Mid-market wholesale typically 8 to 15x DTC.

**Sales Credit Memos in numerator?**
Subtracted (they reverse the original Invoice value).

**Includes shipping?**
Yes if shipping posts to revenue.

**Multi-Company AOV?**
Each Company separately + consolidated row.

**Quote-to-Order conversion: does this card see Quotes?**
No, only converted/posted Sales Invoices.
