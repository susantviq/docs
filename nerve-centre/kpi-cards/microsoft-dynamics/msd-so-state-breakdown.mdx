## Known limitations / merchant FAQs

{/* HUMAN_AUTHORED:faqs */}
**BC's Status enum?**
Open, Released, Pending Approval, Pending Prepayment.

**Released + partial ship?**
Subset of Released where Qty Shipped > 0 but not all lines shipped.

**Custom workflow states?**
Mapped via field map.
