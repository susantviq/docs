## At a glance

{/* HUMAN_AUTHORED:tldr */}
> **Required-Attribute Completeness** is the share of your listings that have every category-mandated attribute filled in, such as colour, size, material, and occasion. Etsy uses attributes to power filtered search and category browsing, so a listing missing its required attributes is harder for buyers to find and can look incomplete next to fully tagged competitors. An Etsy seller cares because attribute completeness is one of the cheapest ways to improve discoverability without spending on ads. Good looks like completeness at or near 100%; below the alert line means a meaningful slice of your catalogue is invisible to attribute-based filters.

| | |
| --- | --- |
| **What it counts** | The percentage of active listings that have all attributes Etsy marks as required for their category populated. |
| **Sample type** | Backend API data from Etsy, refreshed on the standard data refresh. |
| **Why it matters** | Missing required attributes weaken placement in filtered and faceted Etsy search, costing free, high-intent traffic. |
| **Reading the value** | Read it as a percentage of your catalogue that is fully attributed. Higher is better; a dip usually means new or recently edited listings skipped required fields. |
| **Currency** | percent |
| **Time window** | `RT` |
| **Alert trigger** | `<90%` |
| **Sentiment key** | `ets_attribute_completeness` |
| **Roles** | owner, operations |
{/* /HUMAN_AUTHORED:tldr */}

## Calculation

Vortex IQ checks each active listing against the set of attributes Etsy marks as required for that listing's category, then counts a listing as complete only when every required attribute is populated. The card divides complete listings by total active listings to give a percentage. Because required attributes vary by category, a listing that is fully complete in one category may need different fields in another, so the check is evaluated per listing rather than against a single fixed list. The value updates in real time as you fill attributes or publish new listings.

{/* HUMAN_AUTHORED:worked_example */}
*Illustrative numbers.* On 14 Jun 26 a clothing seller sees completeness slip to 87%, below the 90% line, after bulk-importing 40 new listings that skipped the size and material attributes. They filter the catalogue to the incomplete listings, batch-fill the missing colour, size, and material values, and add it to their listing checklist so future imports include required attributes from the start. Completeness climbs back above 90% the same afternoon. ## Reconciling against Etsy Shop Manager

{/* HUMAN_AUTHORED:reconcile */}
**Where to look in Etsy Shop Manager:**

Open Shop Manager > Listings and edit individual listings to see the Attributes section, where Etsy marks which fields are required for the chosen category. The listing editor flags missing required attributes as you work through each item.

**Why the Vortex IQ value may legitimately differ:**

| Reason | Direction | What to do |
| --- | --- | --- |
| **Category required-set changes.** Etsy can update which attributes are required for a category over time. | Variable | Re-review listings in affected categories after Etsy updates its requirements. |
| **Optional versus required scope.** The card counts only required attributes, not every optional one Shop Manager offers. | Variable | Fill optional attributes too for extra discoverability, but the card only grades the required set. |
| **Recently edited listings.** A just-saved listing may not have synced before the refresh. | Marginal | Recheck after the next cycle to confirm a fix registered. |

**Cross-connector reconciliation:** If the same products are also under-attributed on another channel, open Vortex Mind to investigate whether a shared source feed is omitting the fields everywhere.
{/* /HUMAN_AUTHORED:reconcile */}

## Known limitations / merchant FAQs

{/* HUMAN_AUTHORED:faqs */}
**Q: Does this count optional attributes too?**
No. The card measures only the attributes Etsy marks as required for each listing's category. Filling optional attributes still helps discoverability, but it does not change this percentage.

**Q: One listing went from complete to incomplete on its own, why?**
Etsy occasionally updates the required attribute set for a category, which can make a previously complete listing fall short. Re-open the listing in Shop Manager to fill any newly required fields.

**Q: Why does my Etsy Shop Manager show a different number?**
Usually a scope or timing difference: Shop Manager shows required fields per individual listing, while this card aggregates across the whole catalogue, and a just-edited listing may not have synced before the latest refresh.

**Q: Can I customise the alert threshold?**
Yes. Sensitivity thresholds are configurable per profile in the Sensitivity tab. The default alerts below 90%, but you can raise it toward 100% if attribute coverage is a priority for your search strategy.
