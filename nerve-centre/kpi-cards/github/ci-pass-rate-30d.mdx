## At a glance

| | |
| --- | --- |
| **What it measures** | workflow_runs with conclusion=success / all completed runs (conclusion not null) created within 30d, x100, across the top 10 repos. |
| **Source** | GitHub REST API (runs) |
| **Time window** | `30D` |
| **Alert trigger** | `<80%` |
| **Sensitivity band** | `vc_ci_pass_rate`: good 95, bad 80 (Higher is better) |
| **Roles** | owner, engineering |
| **Chart** | gauge |

## Calculation

```
workflow_runs with conclusion=success / all completed runs (conclusion not null) created within 30d, x100, across the top 10 repos.
```

Computed live by the GitHub engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.

### Tracked live in Vortex IQ Nerve Centre

Connect GitHub in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
