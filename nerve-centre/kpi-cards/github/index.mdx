[KPI Cards](/nerve-centre/kpi-cards) / **GitHub** · [Sentiment](/nerve-centre/kpi-cards/github/sentiment)

Vortex IQ tracks the engineering health of the connected GitHub account: deploy cadence (commits and releases), pull-request age, CI pass rate, and repository activity. Cards derive from the REST v3 API (repos, pull requests, Actions runs, commits, releases). Repo-detail cards need a token with repo scope; a token that can only see public metadata renders the repo-list cards.
