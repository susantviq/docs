## At a glance

| | |
| --- | --- |
| **What it measures** | Median of (now - created_at) in days across all open PRs; drives vc_pr_age_days (lower is better). |
| **Source** | GitHub REST API (pulls) |
| **Time window** | `RT` |
| **Alert trigger** | `>14 days` |
| **Sensitivity band** | `vc_pr_age_days`: good 3, bad 14 (Lower is better) |
| **Roles** | owner, engineering |
| **Chart** | kpi |

## Calculation

```
Median of (now - created_at) in days across all open PRs; drives vc_pr_age_days (lower is better).
```

Computed live by the GitHub engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.

### Tracked live in Vortex IQ Nerve Centre

Connect GitHub in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
