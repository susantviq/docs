## At a glance

| | |
| --- | --- |
| **What it measures** | Delivery-event (commits + releases) change_pct vs the prior 30d; fires on a stall per the vc_deploy_cadence band. |
| **Source** | GitHub REST API (derived) |
| **Time window** | `30D vsP` |
| **Alert trigger** | `drop >50% vsP` |
| **Sensitivity band** | `vc_deploy_cadence`: good 0, bad -50 (Trend (drop is the alarm)) |
| **Roles** | owner, engineering |
| **Chart** | kpi |

## Calculation

```
Delivery-event (commits + releases) change_pct vs the prior 30d; fires on a stall per the vc_deploy_cadence band.
```

Computed live by the GitHub engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.

### Tracked live in Vortex IQ Nerve Centre

Connect GitHub in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
