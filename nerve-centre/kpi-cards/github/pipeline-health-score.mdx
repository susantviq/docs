## At a glance

- **Category:** Executive Command Centre
- **Type:** Supporting Metrics
- **Chart:** gauge
- **Format:** score
- **Time window:** 30D
- **Alert trigger:** <70


## Calculation

0-100 composite = 0.4 x CI pass rate + 0.3 x PR-age score (100 at <=3d, 0 at >=14d) + 0.3 x deploy-cadence score (100 + cadence change_pct, clamped 0-100).
