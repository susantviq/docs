Verifies Clarity API access, session capture volume, dead clicks, quick-backs, and checkout-path frustration signals.

## What this audit checks

### Auth + session capture
- API token valid
- Data Export API accessible
- Session count stable vs 1-day baseline

### Behaviour signals
- Dead-click rate within baseline
- Quick-back rate healthy
- Rage-click rate monitored

### Page / checkout UX
- Checkout-path frustration signals monitored
- Scroll depth above floor

### Funnel analysis
- Session conversion rate within baseline
- Cart abandonment rate healthy
- Goal completions tracked

### Cross-platform
- Clarity session volume vs ecommerce conversion divergence

## Severity thresholds

| Signal | Warn | Critical |
