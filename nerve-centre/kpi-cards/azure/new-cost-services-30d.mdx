| | |

| **What it measures** | Count of ServiceName values with Cost > 0 in the current 30d window but zero cost in the previous 30d window; new services quietly adding spend. |
| **Source** | Azure Cost Management (derived) |

| **Roles** | owner, engineering, finance |
| **Chart** | kpi |

> Requires the Cost Management Reader role granted to the app registration on the subscription; without it this card shows no data.

## Calculation

```
Count of ServiceName values with Cost > 0 in the current 30d window but zero cost in the previous 30d window; new services quietly adding spend.
```

Computed by the Microsoft Azure engine from daily cost buckets over a 60-day window (current 30 days plus the previous 30 for trend comparisons), refreshed on the standard sync. The engine degrades to no data rather than estimating.
