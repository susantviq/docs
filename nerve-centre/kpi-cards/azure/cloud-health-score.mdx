## At a glance

- **Category:** Executive Command Centre
- **Type:** Key Metrics
- **Chart:** gauge
- **Format:** score
- **Time window:** 30D vsP
- **Alert trigger:** `<70`


## Calculation

Composite 0-100: start at 100, minus 30 if 30d spend is up >50% vsP (15 if up >25%), minus 10 if the top service is >80% of 30d spend, minus 20 if subscription state is not Enabled. All inputs from the subscription read + the 60d cost query.
