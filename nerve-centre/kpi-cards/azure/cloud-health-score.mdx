## At a glance

| | |
| --- | --- |
| **What it measures** | Composite 0-100: start at 100, minus 30 if 30d spend is up >50% vsP (15 if up >25%), minus 10 if the top service is >80% of 30d spend, minus 20 if subscription state is not Enabled. All inputs from the subscription read + the 60d cost query. |
| **Source** | Azure Cost Management (derived) |
| **Time window** | `30D vsP` |
| **Alert trigger** | `<70` |
| **Sensitivity band** | `cloud_health_score`: good 90, bad 70 (higher is better) |
| **Roles** | owner, engineering, finance |
| **Chart** | gauge |

> Requires the Cost Management Reader role granted to the app registration on the subscription; without it this card shows no data.

## Calculation

```
Composite 0-100: start at 100, minus 30 if 30d spend is up >50% vsP (15 if up >25%), minus 10 if the top service is >80% of 30d spend, minus 20 if subscription state is not Enabled. All inputs from the subscription read + the 60d cost query.
```

Computed by the Microsoft Azure engine from daily cost buckets over a 60-day window (current 30 days plus the previous 30 for trend comparisons), refreshed on the standard sync. The engine degrades to no data rather than estimating.

### Tracked live in Vortex IQ Nerve Centre

Connect Microsoft Azure in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
