## Calculation

Amplitude Tracking Health Score is a composite built from four component checks - core events firing, funnel conversion stable, retention healthy, and no attribution drift - each contributing to a single combined score that Vortex IQ refreshes in near real time. A weakness in any one component pulls the overall score down, so a falling number points you toward whichever signal has degraded rather than giving a single root cause. See the At a glance summary above for what the metric tracks and the worked example below for a typical reading.

## Reconciling against Amplitude

{/* HUMAN_AUTHORED:reconcile */}
**Where to look in Amplitude's own dashboard:**

This score is a Vortex IQ composite, so Amplitude has no single matching number; instead you reconcile each component separately. Use Event Segmentation to confirm core events are firing, the Funnels report to check conversion stability, the Retention report for the retention component, and your attribution or marketing dashboards for drift. The Data section's event volume and ingestion views help verify the tracking foundation underneath all four. Match the date range and segments across each report to the Vortex IQ profile.

**Why the Vortex IQ value may legitimately differ:**

| Reason | Direction | What to do |
| --- | --- | --- |
| **Period boundary.** Vortex IQ blends a real-time read with a 7-day view; Amplitude's individual reports may use different ranges per component. | Variable | Match the date range on each component report. |
| **Time zone.** Amplitude buckets by the project time zone; Vortex IQ aligns to the merchant reporting time zone. | Marginal | Confirm both use the same time zone. |
| **Filter or segment scope.** Profile-level filters narrow the Vortex IQ view; an all-account Amplitude report will look broader. | Variable | Align segment and event filters across components. |

## Known limitations / merchant FAQs

{/* HUMAN_AUTHORED:faqs */}
**Q: How often does Amplitude Tracking Health Score update?**
It blends a near real-time read with a rolling 7-day view and refreshes on the standard data refresh (typically every 30-60 minutes for live integrations). Force a manual refresh if you want the latest read during an incident.

**Q: Why does my Amplitude dashboard show a different number?**
Amplitude has no single equivalent because this is a Vortex IQ composite of four separate signals. Reconcile by checking each component (core events, funnel stability, retention, attribution) in its own Amplitude report, matching date ranges and segments.

**Q: How does Amplitude Tracking Health Score relate to other metrics?**
It summarises four component cards into one gauge. When it drops, the contributing cards - core events firing, funnel conversion, D7 retention, and attribution drift - tell you which signal degraded. Use the score as the alert and the components as the diagnosis.

**Q: Can I customise the alert threshold?**
Yes, alert thresholds are configurable per profile in the Alert Rules tab. The default alerts when the score falls below 70; raise or lower it to match how tolerant your team is of instrumentation noise.
