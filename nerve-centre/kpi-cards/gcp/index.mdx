[KPI Cards](/nerve-centre/kpi-cards) / **Google Cloud Platform** · [Sentiment](/nerve-centre/kpi-cards/gcp/sentiment)

Vortex IQ tracks the Google Cloud estate and spend of the connected service account: project and billing-account health render with any working key, while spend cards read the customer's Standard billing export in BigQuery (GCP exposes no spend via a simple REST endpoint, so Vortex IQ never estimates). Configure the billing export table in the connector settings to light up the spend cards.
