## At a glance

| | |
| --- | --- |
| **What it measures** | Gemini request/token usage is NOT exposed by the Gemini API (no usage endpoint). Degrades with reason billing_via_gcp unless a linked GCP billing export supplies it. Never fabricated here. |
| **Source** | Gemini API (derived) |
| **Time window** | `30D vsP` |
| **Alert trigger** | `drop >50% vsP` |
| **Sensitivity band** | `ai_usage_trend`: good 0, bad -50 (Trend (drop is the alarm)) |
| **Roles** | owner, engineering |
| **Chart** | kpi |

> Requires Gemini spend linked through Google Cloud billing; the Gemini API exposes no cost endpoint, so this card shows no data until GCP billing is connected.

## Calculation

```
Gemini request/token usage is NOT exposed by the Gemini API (no usage endpoint). Degrades with reason billing_via_gcp unless a linked GCP billing export supplies it. Never fabricated here.
```

Computed live by the Google Gemini engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.

### Tracked live in Vortex IQ Nerve Centre

Connect Google Gemini in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
