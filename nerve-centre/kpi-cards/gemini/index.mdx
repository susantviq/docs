[KPI Cards](/nerve-centre/kpi-cards) / **Google Gemini** · [Sentiment](/nerve-centre/kpi-cards/gemini/sentiment)

Vortex IQ tracks the Google Gemini model catalogue and capability surface of the connected API key: models available, model families, context windows, and generation capabilities. Cards derive from the /v1beta/models endpoint. Gemini has no native cost API (it bills through Google Cloud), so the spend cards stay empty until the Google Cloud connector supplies billing.
