## At a glance

| | |
| --- | --- |
| **What it measures** | Composite 0-100: 60 for the API being reachable and the key authenticating on /v1beta/models, plus up to 40 for a non-empty model catalogue. No spend input (spend is not exposed by the Gemini API). |
| **Source** | Gemini API (models) |
| **Time window** | `RT` |
| **Alert trigger** | `<70` |
| **Sensitivity band** | `cloud_health_score`: good 90, bad 70 (Higher is better) |
| **Roles** | owner, engineering |
| **Chart** | gauge |

## Calculation

```
Composite 0-100: 60 for the API being reachable and the key authenticating on /v1beta/models, plus up to 40 for a non-empty model catalogue. No spend input (spend is not exposed by the Gemini API).
```

Computed live by the Google Gemini engine on the standard sync. The engine degrades to no data rather than estimating: if the source is unreadable, the card says so instead of guessing.

### Tracked live in Vortex IQ Nerve Centre

Connect Google Gemini in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
