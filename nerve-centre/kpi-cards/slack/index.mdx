[KPI Cards](/nerve-centre/kpi-cards) / **Slack**

Slack is connected to Vortex IQ as a delivery channel via an incoming webhook. Because a webhook is send-only, these cards confirm the channel is wired and healthy rather than reporting analytics: Vortex IQ can push alerts and digests to the channel, but Slack exposes no read API for a webhook to draw metrics from.
