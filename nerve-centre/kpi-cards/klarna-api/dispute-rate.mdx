## At a glance

{/* HUMAN_AUTHORED:tldr */}
> Klarna disputes in active state (pre-resolution). Includes won-recently and lost-recently. Leading indicator for chargeback (buyer-protection-claim) rate.

| | |
| --- | --- |
| **What it counts** | Active claims and recently-resolved divided by captured. |
| **Time window** | `30D vsP`. |
| **Alert trigger** | `>1%`. |
| **Sentiment key** | `gauge_inverse: good<=0.5, warn>1` |
| **Roles** | owner, operations |
{/* /HUMAN_AUTHORED:tldr */}

## Calculation

Calculated automatically from your Klarna data. See the At a glance summary above for what the metric tracks and the worked example below for a typical reading.
