[KPI Cards](/nerve-centre/kpi-cards) / **X (Twitter)** · [Audit](/nerve-centre/kpi-cards/twitter/audit) · [Sentiment](/nerve-centre/kpi-cards/twitter/sentiment)

Vortex IQ tracks the brand's native organic X (Twitter) presence: audience size, engagement on what gets posted, posting cadence and reach. All 23 cards derive from the X API v2 (`/2/users/me` + the account's recent posts with `public_metrics`) via the account owner's OAuth connection. This is the native social view, not the GA social-referral traffic view (that lives in the analytics connector).
