## At a glance

| | |
| --- | --- |
| **What it measures** | Sum of public_metrics.impression_count over posts in the last 30d. Owner user-context token only; app-only bearer tokens render no data. |
| **Source** | X API v2 (posts) |
| **Time window** | `30D vsP` |
| **Alert trigger** | `drop >20% vsP` |
| **Sensitivity band** | `reach`: good 0, bad -20 (trend based) |
| **Roles** | owner, marketing |
| **Chart** | kpi |

> Requires the account owner's user-context OAuth token; app-only bearer tokens cannot see impressions.

## Calculation

```
Sum of public_metrics.impression_count over posts in the last 30d. Owner user-context token only; app-only bearer tokens render no data.
```

Computed by the X (Twitter) engine from `/2/users/me` and the account's recent posts (`/2/users/{id}/tweets` with `public_metrics`), refreshed on the standard sync. Reading posts requires the X API Basic tier; the engine degrades to no data rather than estimating.

Connect your X (Twitter) account in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
