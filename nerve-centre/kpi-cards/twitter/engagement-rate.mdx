## At a glance

| | |
| --- | --- |
| **What it measures** | Avg per-post (likes + replies + reposts + quotes) / followers x 100 across posts in the last 30d. |
| **Source** | X API v2 (posts) |
| **Time window** | `30D` |
| **Alert trigger** | `<1%` |
| **Sensitivity band** | `engagement_rate`: good 3, bad 1 (higher is better) |
| **Roles** | owner, marketing |
| **Chart** | gauge |

## Calculation

```
Avg per-post (likes + replies + reposts + quotes) / followers x 100 across posts in the last 30d.
```

Computed by the X (Twitter) engine from `/2/users/me` and the account's recent posts (`/2/users/{id}/tweets` with `public_metrics`), refreshed on the standard sync. Reading posts requires the X API Basic tier; the engine degrades to no data rather than estimating.

### Tracked live in Vortex IQ Nerve Centre

Connect your X (Twitter) account in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
