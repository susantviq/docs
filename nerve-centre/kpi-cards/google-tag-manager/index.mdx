Vortex IQ Nerve Centre tracks **14** KPI pulses for Google Tag Manager stores. Each metric has its own page: definition, calculation, why it matters, and what to do when it moves.

{/* HUMAN_AUTHORED:landing_positioning */}
The Google Tag Manager connector brings the Vortex IQ **AI OS** to teams running GTM — but the data surfaced here is **page-performance and Web Vitals** sourced via GTM-driven instrumentation, not tag config. The **Nerve Centre** tracks 14 KPI pulses including Core Web Vitals (*LCP Mobile*, *CLS Mobile*, *INP Mobile*, *CWV Pass Rate*) and Lighthouse scores (*Performance Mobile/Desktop*, *Accessibility*, *Best Practices*, *SEO*). **Vortex Mind** investigates when Core Web Vitals degrade or Lighthouse scores drop; **Ask Viq™** lets you ask in plain English with citations back to the source card.
