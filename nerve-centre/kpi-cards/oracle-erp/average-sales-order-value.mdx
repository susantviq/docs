> Mean Sales Order line total. Mid-market B2B AOVs typically run 8 to 15x DTC.

## At a glance

{/* HUMAN_AUTHORED:tldr */}
> Mean Sales Order value. For B2B Fortune 500 distributors typically $20K to $200K depending on industry; for B2C / DTC much lower.

| | |
| --- | --- |
| **What it counts** | `SUM(ordered_amount) / COUNT(SO)` for SOs created in the window. |
| **Tax treatment** | Net of tax. |
| **Shipping** | Included on SO line. |
| **Discounts** | Post-discount. |
| **Cancelled** | Excluded. |
| **Currency** | Reporting ledger. |
| **Time window** | `30D vsP` |
| **Alert trigger** | `drop >10% vsP` |
| **Sentiment key** | `aov_trend` |
| **Roles** | owner, finance |
{/* /HUMAN_AUTHORED:tldr */}

## Calculation

Calculated automatically from your Oracle ERP Cloud data. See the At a glance summary above for what the metric tracks and the worked example below for a typical reading.

## Worked example

{/* HUMAN_AUTHORED:worked_example */}
A US Fortune 500 distributor on Oracle ERP Cloud. 30D window 14 Mar 26 to 12 Apr 26.

| | This period | Prior |
| --- | --- | --- |
| Sales Orders | 4,820 | 4,720 |
| Total SO value | $124M | $128M |
| **Average SO** | **$25,725** | **$27,118** |

Five things to notice:

1. **AOV dropped 5.1% vsP.** Within healthy range; if it continues 3 periods, investigate mix shift.
2. **Volume up but value down** = customers buying smaller orders or smaller-cart customers gaining share.
3. **Per-channel cut** reveals which channel is dragging.
4. **Compare to Top B2B Accounts** for whether top customers are buying smaller.
5. **DTC vs B2B mix** changes AOV dramatically.
{/* /HUMAN_AUTHORED:worked_example */}

## Known limitations / merchant FAQs

{/* HUMAN_AUTHORED:faqs */}
**Why does B2B AOV swing so much vs DTC?**
B2B order sizes vary by customer; one large customer placing a big order can move the average noticeably.

**Includes drop-ship orders?**
Yes by default.

**Multi-BU averaging?**
Card averages globally; drill-down per-BU available.
