## Worked example

{/* HUMAN_AUTHORED:worked_example */}
A Fortune 500 retailer's top 5 SKUs by inventory value:
| SKU | On-hand value |
| --- | --- |
| FURN-SOFA-EXEC | $4,820,000 |
| FURN-DESK-CEO | $3,420,000 |
| ELEC-TV-OLED-65 | $2,840,000 |
| FURN-CHAIR-EXEC | $2,420,000 |
| ELEC-LAPTOP-PRO | $2,180,000 |

Five things to notice:
1. **Top 20 typically hold 60-80% of value.** Operations focus.
2. **High-value SKUs need cycle counts more often.**
3. **Pair with [Inventory Aging](/nerve-centre/kpi-cards/oracle-erp/inventory-aging)**: high-value + aged = priority write-down.
4. **Insurance / loss-prevention focus.**
5. **Drill into per-warehouse**: which DC holds the high-value stock.
