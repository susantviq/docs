## At a glance

{/* HUMAN_AUTHORED:tldr */}
> Number of RMA (Return Material Authorisation) Sales Orders created in the period. The volume side; pair with [Credit Memo Value](/nerve-centre/kpi-cards/oracle-erp/oerp-credit-memos-value) for $.

| | |
| --- | --- |
| **What it counts** | `COUNT(SO WHERE order_type = RMA)` in window. |
| **Currency** | n/a. |
| **Time window** | `30D vsP` |
| **Alert trigger** | `up >20% vsP` |
| **Sentiment key** | `returns_trend` |
| **Roles** | owner, operations |
{/* /HUMAN_AUTHORED:tldr */}

## Calculation

Calculated automatically from your Oracle ERP Cloud data. See the At a glance summary above for what the metric tracks and the worked example below for a typical reading.

## Worked example

{/* HUMAN_AUTHORED:worked_example */}
A US Fortune 500 retailer on Oracle ERP Cloud. 30D window.

| | This period | Prior |
| --- | --- | --- |
| RMA SO count | 384 | 348 |
| Return rate vs orders shipped | 8.0% | 7.6% |

Five things to notice:

1. **10% increase vsP, just below 20% alert.** Watching.
2. **Pair with reason codes** to see if quality / sizing / shipping issues spiking.
3. **Per-SKU drill** identifies problem products.
4. **Per-channel** distinguishes commerce returns from B2B.
5. **Cross-reference [Credit Memo Value](/nerve-centre/kpi-cards/oracle-erp/oerp-credit-memos-value)** for $ impact.
{/* /HUMAN_AUTHORED:worked_example */}

## Known limitations / merchant FAQs

{/* HUMAN_AUTHORED:faqs */}
**Healthy return rate?**
Apparel 15-30%, electronics 8-15%, B2B distribution 1-5%, grocery &lt;1%.

**Includes warranty returns?**
Configurable. Default includes; tag warranty separately for cleaner trend.

**Multi-BU?**
Yes.
