## At a glance

{/* HUMAN_AUTHORED:tldr */}
> SKUs with on-hand quantity below the reorder point in Oracle Inventory Cloud Min/Max planning. The forward-looking shortage list.

| | |
| --- | --- |
| **What it counts** | `WHERE on_hand < reorder_point` per item. |
| **Currency** | n/a (count + units). |
| **Time window** | Real-time. |
| **Alert trigger** | `any below reorder point` |
| **Roles** | owner, operations |
{/* /HUMAN_AUTHORED:tldr */}

## Calculation

Calculated automatically from your Oracle ERP Cloud data. See the At a glance summary above for what the metric tracks and the worked example below for a typical reading.

## Worked example

{/* HUMAN_AUTHORED:worked_example */}
84 SKUs below reorder point. Top 5 high-priority (high velocity, low cover):
| SKU | On hand | Reorder pt | Days cover |
| --- | --- | --- | --- |
| WIDGET-A | 24 | 100 | 2 |
| GADGET-B | 8 | 50 | 3 |
| DEVICE-C | 0 | 30 | 0 (OOS) |

Five things: (1) prioritise by days-cover, (2) auto-PO via Oracle Procurement if configured, (3) check supplier lead time, (4) communicate to Sales for substitution if stockout imminent, (5) cross-reference [OOS with Open SO Demand](/nerve-centre/kpi-cards/oracle-erp/oos-with-open-sales-order-demand).
{/* /HUMAN_AUTHORED:worked_example */}

## Known limitations / merchant FAQs

{/* HUMAN_AUTHORED:faqs */}
**Reorder point logic?**
Per Oracle Min/Max planning configuration: typically `lead_time_demand + safety_stock`.

**Multi-warehouse?**
Yes; per-org alert.
