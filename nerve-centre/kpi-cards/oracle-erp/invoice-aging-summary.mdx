> A/R balance bucketed by 0-30 / 31-60 / 61-90 / 91-120 / 120+ days. Cash-flow telemetry.

## At a glance

{/* HUMAN_AUTHORED:tldr */}
> Aging summary: total open AR sliced by 5 buckets. Same data as [A/R Aging Detail](/nerve-centre/kpi-cards/oracle-erp/a-r-aging-detail), summary view (no per-customer breakdown).

| | |
| --- | --- |
| **What it counts** | `SUM(amount_due_remaining)` per bucket: Current, 0-30 PD, 31-60, 61-90, 91-120, 120+. |
| **Tax treatment** | Gross. |
| **Currency** | Reporting ledger. |
| **Time window** | Real-time snapshot. |
| **Alert trigger** | `>30% in 60+ bucket` |
| **Roles** | owner, finance |
{/* /HUMAN_AUTHORED:tldr */}

## Calculation

Calculated automatically from your Oracle ERP Cloud data. See the At a glance summary above for what the metric tracks and the worked example below for a typical reading.

## Worked example

{/* HUMAN_AUTHORED:worked_example */}
A US Fortune 500 distributor on Oracle ERP Cloud. Snapshot 14 Apr 26.

| Bucket | Open AR |
| --- | --- |
| Current | $84,200,000 |
| 0-30 PD | $32,400,000 |
| 31-60 PD | $14,800,000 |
| 61-90 PD | $8,400,000 |
| 91-120 PD | $4,800,000 |
| 120+ PD | $3,600,000 |
| **Total Open AR** | **$148,200,000** |

Five things to notice:

1. **11.4% in 60+ buckets ($16.8M).** Below 30% alert threshold.
2. **57% Current** is healthy.
3. **Trend matters:** if Current % is dropping, slippage is happening.
4. **Compare across BUs:** different BUs have different aging profiles.
5. **Use detail card** for per-customer drill.
{/* /HUMAN_AUTHORED:worked_example */}

## Known limitations / merchant FAQs

{/* HUMAN_AUTHORED:faqs */}
**Difference vs detail card?**
Summary is bucket totals only; detail breaks down per customer.

**Multi-Ledger?**
Yes via filter.

**Includes Credit Memos?**
Net-of-CM at customer level.
