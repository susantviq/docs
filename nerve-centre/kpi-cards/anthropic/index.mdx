[KPI Cards](/nerve-centre/kpi-cards) / **Anthropic (Claude)** · [Sentiment](/nerve-centre/kpi-cards/anthropic/sentiment)

Vortex IQ tracks the AI spend and usage of the connected Anthropic organisation: spend level and trend, token volume by type (uncached, cache read, cache creation, output), model mix and prompt-cache effectiveness. Cards derive from /v1/models plus the organisation Admin usage and cost reports. Spend and usage cards require an organisation Admin key (sk-ant-admin...); a plain API key renders only the model cards.
