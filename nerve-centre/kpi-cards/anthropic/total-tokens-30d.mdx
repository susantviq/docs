## At a glance

| | |
| --- | --- |
| **What it measures** | uncached input + cache reads + cache creation + output tokens summed over the last 30d. |
| **Source** | Anthropic Admin API (usage) |
| **Time window** | `30D vsP` |
| **Alert trigger** | `drop >50% vsP` |
| **Sensitivity band** | `ai_usage_trend`: good 0, bad -50 (trend based (usage drop = bad)) |
| **Roles** | owner, engineering |
| **Chart** | kpi |

> Requires an organisation Admin API key; with a plain key this card shows no data.

## Calculation

```
uncached input + cache reads + cache creation + output tokens summed over the last 30d.
```

Computed by the Anthropic (Claude) engine from daily Admin-report buckets over a 60-day window (current 30 days plus the previous 30 for trend comparisons), refreshed on the standard sync. The engine degrades to no data rather than estimating.
