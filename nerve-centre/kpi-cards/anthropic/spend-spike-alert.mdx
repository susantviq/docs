## At a glance

| | |
| --- | --- |
| **What it measures** | Spend change vs the prior 30d; fires on a spike per the ai_spend_trend band. |
| **Source** | Anthropic Admin API (derived) |
| **Time window** | `30D vsP` |
| **Alert trigger** | `up >50% vsP` |
| **Sensitivity band** | `ai_spend_trend`: good 10, bad 50 (trend inverse (rising spend = bad)) |
| **Roles** | owner, finance |
| **Chart** | kpi |

> Requires an organisation Admin API key; with a plain key this card shows no data.

## Calculation

```
Spend change vs the prior 30d; fires on a spike per the ai_spend_trend band.
```

Computed by the Anthropic (Claude) engine from daily Admin-report buckets over a 60-day window (current 30 days plus the previous 30 for trend comparisons), refreshed on the standard sync. The engine degrades to no data rather than estimating.

### Tracked live in Vortex IQ Nerve Centre

Connect Anthropic (Claude) in [Settings, Connectors](https://app.vortexiq.ai/v2/settings?tab=sources) and this card renders live alongside the rest of the connector's metrics.
