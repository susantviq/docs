Connecting Volusion to Vortex IQ gives the AI OS a live read on your Volusion data, feeding the Nerve Centre dashboard, Vortex Mind diagnostics, and Ask Viq.

## What data Vortex IQ reads from Volusion

- **Order**
- **Product**
- **Customer**
- **Refund**
- **InventoryLevel**

## How to connect

<Note>
  Volusion uses credential-based authentication rather than OAuth. You provide these values directly rather than approving a redirect.
</Note>

<Steps>
  <Step title="Open Connected Sources">
    In your Vortex IQ workspace, go to **Settings → Connected Sources**. You need Admin role in the workspace to connect sources.
  </Step>
  <Step title="Find the Volusion card">
    Locate the Volusion connector card and click **+ Connect**. The connector drawer opens with a credential form.
  </Step>
  <Step title="Gather your credentials from Volusion">
    You will need:

    - **Store URL**: Your Volusion store host, e.g. https://www.yourstore.com - every API and CSV-export call is relative to it.
    - **API Token / Encrypted Password**: Volusion API token (modern API) or the EncryptedPassword for the generic CSV export. Generate under Account → API.
    - **API Login**: API Login user for the classic generic export endpoint (paired with the Encrypted Password).
  </Step>
  <Step title="Enter credentials in Vortex IQ">
    Paste each value into its matching field in the connector drawer.
  </Step>
  <Step title="Verify and connect">
    Click **Verify and Connect**. Vortex IQ makes a test API call to validate the credentials before saving them.
  </Step>
</Steps>

<Note>
  Vortex IQ only ever requests read-only access. Where Volusion offers scoped or read-only API keys, use one.
</Note>

## Available KPI cards

Vortex IQ populates **33** Nerve Centre cards from your Volusion data. See the [Volusion KPI card reference](/nerve-centre/kpi-cards/volusion) for the full list with definitions, calculations, and sentiment bands.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Credential verification fails">
    Re-check each value against the Volusion developer console for typos or trailing whitespace. If a scope or permission is missing, Volusion will typically return a 401 or 403 on the verification call rather than a generic failure.
  </Accordion>
  <Accordion title="Cards show no data after connecting">
    Allow time for the first sync to complete; large accounts can take longer. If cards are still empty after an hour, disconnect and reconnect to confirm the credentials were saved correctly.
  </Accordion>
</AccordionGroup>
